# Project 11: Infra Changes with Branching Policy

## Objective
Implement infrastructure changes using a feature branch
and a Pull Request review workflow.

## Branching Strategy
- main: stable infrastructure configuration
- feature/project-11-infra-changes: development branch

## Workflow
1. Create feature branch
2. Make infrastructure changes
3. Commit changes
4. Push feature branch to GitHub
5. Create Pull Request
6. Review changes
7. Merge PR into main
